# 傅里叶光学：传送门实验室主题

## 设计与范围

2026-10-23，按用户指定的 Rick and Morty 方向实现，不更换课程布局。
以深空青黑框架、传送门绿、漫画描边和逐集剧照建立辨识度，正文使用浅色高对比阅读面。
课程目录、四种学习模式、公式、实验、正式答案和进度命名空间保持原有职责；
不修改网站首页的 JoJo 主题或《物理光学》。

- 主题入口：`portal-theme.css`、`portal-theme.js`。主题脚本在 `app.js` 前加载，
  `renderShell()` 调用 `FourierPortalTheme.apply()` 更新当前小节装饰，不写学习进度。
- 剧照按已实现末级小节顺序映射：1.1、1.2.1、1.2.2、1.3.1、1.3.2、1.3.3、
  1.4.1、1.4.2、1.4.3 → S01E01–S01E09。不要把教材编号直接当成剧集编号。
- 每节主视觉使用对应剧照和该集两张角色贴纸，目录增加逐节不同的角色缩略图，
  桌面侧栏以该集三角色组图代替重复主剧照。九组角色互不重复；窄屏保留主视觉拼贴。
- 教材页码与入口移出标题图，作为标题下、模式入口前的独立资料条；
  1.3.1 也保留。网站延续不托管教材的来源说明。
- 四模式入口使用本地绘制的传送枪、跨维电视、现场笔记及 Meeseeks 方盒 SVG。
  实验台采用漫画仪器边框和指示条；判断区、讲义与正式题按节使用角色贴纸。
  正文保持浅色高对比，保留原图颜色编码与学习布局。
- 开场保留三段连续、可拖动回看的光传播 / FFT 计算 / 全息重建。
  传送门轻微摆动/呼吸与播放状态联动，暂停、关闭和切到后台时停止；低动态偏好不自动播放。
  光场算法没有改动，仅修改强度伪彩、描边及文字配色。
- 不删改教学文字，不用剧情替代物理模型，不新增闯关或虚构学习成效。

## 快捷按钮根因与回归

普通小节原有 `.independent-labs-active .quick-tools { position: static; }`，
1.3.1 原有 sticky 样式及手机端 static 覆盖，导致按钮在不同页面表现不一致。
现在仅由共用 `.quick-tools` 的 `position: fixed` 控制，并保留安全区间距；
符号按钮始终可达，返回顶部仍在滚动超过 480px 后显示。
两者不参与长页排版，不允许节专用样式重新改成 static/sticky。
